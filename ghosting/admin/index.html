Respuestas registradas

Alertas automáticas: no elegible, otra situación (fuera del binario), rápida (menos de 20 s en un recorrido completo), uniforme (los 4 ítems iguales; solo informativo). Las respuestas reales no se borran: se marcan como inválidas y quedan fuera de todo análisis.

Importar respuestas obtenidas por otros medios

Mismas variables que el cuestionario web. Cada fila se valida antes de importar. Las filas importadas quedan marcadas con origen “import” y el nombre del lote. No cargues datos inventados en la base real: para pruebas, marcá el lote como prueba.

Configuración del estudio

La fecha de corte oficial se usa como valor inicial del filtro “Fecha de corte” del análisis. La web puede seguir recibiendo respuestas después: el TP analiza solo las anteriores al corte.

Limpiar datos de prueba

Borra definitivamente todas las respuestas marcadas como prueba. Las respuestas reales no se pueden borrar desde el panel.
